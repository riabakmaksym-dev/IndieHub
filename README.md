# IndieHub

**IndieHub** — платформа для розробників-початківців, яка допомагає знаходити однодумців, створювати команди та спільно розробляти інді-ігри.

## Технології

- React
- Vite
- React Router
- ESLint
- Prettier
- Husky
- Cypress

## Запуск проєкту

Встановити залежності:

```bash
npm install
```

Запустити проєкт у режимі розробки:

```bash
npm run dev
```

Перевірити код:

```bash
npm run lint
```

Перевірити форматування:

```bash
npx prettier --check .
```
